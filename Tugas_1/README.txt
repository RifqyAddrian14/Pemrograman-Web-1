GUITAR HOUSE — Tugas Pemrograman Web
====================================
Isi folder:
- home.html
- galeri.html
- produk.html
- kontak.html
- style.css

Cara menjalankan:
1. Ekstrak ZIP ini.
2. Pastikan semua file HTML dan style.css berada dalam folder yang sama.
3. Buka home.html dengan browser (Chrome, Edge, Firefox, dll.).
4. Klik menu Home, Galeri, Produk, atau Kontak untuk berpindah halaman.

Catatan:
- Header gambar dan 4 menu navigasi tampil di semua halaman.
- Website memakai tabel, hyperlink, dan contoh tabel di dalam tabel.
- Foto memakai URL Unsplash sehingga internet diperlukan untuk menampilkan gambar.
- Form kontak membuat draft email melalui aplikasi email perangkat; ini bukan backend pengiriman pesan.
- Semua teks, kategori, dan kontak merupakan contoh untuk tugas.
